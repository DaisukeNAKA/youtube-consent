共通仕様: 1280×720（16:9）、JPG/PNG 2MB 以下、スマホの一覧で読める文字サイズ（見出しは画像の高さの 1/4 以上）、文字は最大 2 行、文字色は白または黄色に黒縁、日本語フォントは太いゴシック（Noto Sans JP Black 相当）。

> 使い方: 下の 5 候補のうち 1〜2 つを選び、「■指示文」ブロックをそのまま画像生成 AI（ChatGPT の画像生成、Gemini、Midjourney、Canva の AI 等）に貼る。顔写真を添付できる AI には `サムネ用_顔.png` を添える。生成物はこのスキルの標準外なので、出来を見て文言だけ差し替えて再生成する。

## 候補 01 Greg 型（顔大＋見出し 3〜6 字＋黄色帯）
チャンネル主の顔を画面の右 45% に大きく（胸から上、表情は驚き／笑顔）、左に見出し 3〜6 字を 2 段まで。見出しの下に黄色い帯（#FFE500）を斜めに敷き、その上に黒文字でサブ 1 行。
- 見出し（3〜6 字）: {{見出し（例: 買って後悔 / 別物だった / 7分→3分）}}
- サブ（8〜12 字）: {{サブ（例: Apple Watch Ultra 比較）}}

■指示文
```
YouTube のサムネイル画像を 1280×720 で作ってください。
添付の顔写真の人物を右側 45% に大きく配置（胸から上、背景から切り抜き、輪郭に白い縁 6px）。

見出しの下に黄色（#FFE500）の帯を少し斜め（-8°）に敷き、帯の上に黒文字で「{{サブ}}」。
背景は {{背景（例: 濃紺 #101627 のグラデーション / 撮影場所をぼかしたもの）}}。

```

## 候補 03 ビフォーアフター
左右 2 分割。左「Before」に {{前の状態}}、右「After」に {{後の状態}}。中央に太い矢印（→）。上か下に 6〜10 字の一言。

- After: {{例: 3分の完成動画}}
- 一言（6〜10 字）: {{例: AIに丸投げ}}

■指示文
```
YouTube のサムネイル画像を 1280×720 で作ってください。
画面を左右に 2 分割し、左に「{{Before}}」の様子、右に「{{After}}」の様子を写真風に描く。

下部に「{{一言}}」を黄色（#FFE500）文字・黒縁・極太で 1 行。
左右の色調を変える（左は暗め・グレー、右は明るめ・鮮やか）。文字は日本語で指定どおり。他の文字は入れない。
```

## 候補 04 物体クローズ
主役の物（{{製品・画面・道具}}）を画面の 60% で大きく、斜めから。上部または左上に 4〜8 字の見出し。顔は右下に小さめの丸、または無し。
- 物体: {{例: Apple Watch Ultra の実物 / iPhone の画面}}
- 見出し（4〜8 字）: {{例: 実物はこんなに小さい → 実物が小さい}}

```

左上に「{{見出し}}」を白文字・黒縁・極太ゴシックで 1 行（画像の高さの 1/5 の文字サイズ）。
右下に添付の顔写真を丸く切り抜いて小さく配置（無ければ顔なし）。
背景色は {{背景色}}。文字は日本語で指定どおり。他の文字・ロゴは入れない。
```

## 候補 05 テキスト主体
写真を使わず、濃い単色背景に 2 行の大きな文字だけ。1 行目 4〜8 字（主張）、2 行目 6〜12 字（補足）。色は 1 行目 黄、2 行目 白。
- 1 行目（4〜8 字）: {{例: 大後悔です}}
- 2 行目（6〜12 字）: {{例: 早く買えばよかった}}

■指示文
```
YouTube のサムネイル画像を 1280×720 で作ってください。写真は使わない。
背景は濃紺（#101627）の単色。中央に 2 行の文字だけを置く。
1 行目「{{1行目}}」は黄色（#FFE500）・極太ゴシック・画像の高さの 1/3 のサイズ。
2 行目「{{2行目}}」は白・極太ゴシック・1 行目の 60% のサイズ。両方とも黒縁 4px と弱い影。
左寄せ、左右の余白は幅の 8%。文字は日本語で指定どおり。他の要素は入れない。
```

## 書き方メモ（エージェント用。出力時はこの節ごと削除する）
- 見出し語は `edit_plan.json` の headings と `タイトル案.md` の推し案から取り、3〜6 字（Greg 型）／4〜8 字（他）に詰める。言い換えすぎない。数字・英字は半角。
- 顔写真は本編 `work/cut.mp4` から、口が開きすぎていない・目線がカメラのフレームを選ぶ（`ffmpeg -ss 12.5 -i cut.mp4 -frames:v 1 サムネ用_顔.png`）。縦素材なら顔中心にクロップしてから渡す。
- 顔出しチャンネルは 01 を第1候補、レビュー系は 02 か 04、作業系（before/after が明確）は 03、顔なし運用は 05。
- 5 候補すべて埋める（型が同じ案を出さない）。指示文の `{{…}}` は全部埋めて、残さない。
- 色は動画の見た目（濃紺 #101627・黄 #FFE500・白）に揃えると一覧で統一感が出る。
- サムネ画像の生成・確認はスキル標準外。生成後にユーザーが選ぶ前提で、`Codex_アップロード指示.txt` のサムネパスは選ばれたものに差し替える。
