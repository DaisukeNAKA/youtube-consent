# ユニコ 15秒CM『推し、お笑いの相方に。』篇（常用版 E0）

お笑いコンビ「ユニコ」（中塚サンフラワー／リッチャン☆）の15秒CMを、コードから毎回同じ絵と音で再現できる形で制作するための一式です。

- **出力**：9:16（1080×1920）と 16:9（1920×1080）の2本。各 15.000秒・450フレーム。
- **1コマンド**：`./build.sh` で「自作の音楽・効果音の合成 → ラウドネス調整 → 書き出し → 自動QA → 共有用の軽量版」まで実行します。
- **公開しないもの**：肖像写真・ロゴ・書体ファイル・書き出した動画は、このリポジトリに含めていません（`.gitignore`）。企画書・確認事項などの社内メモも置いていません。

120BPM（1拍＝0.5秒＝15フレーム、1小節＝2.0秒）に合わせ、カットと効果音はすべて小節頭か拍頭に置いています。時刻はフレーム番号が正です。

## 仕上がり仕様

| 項目 | 値 |
|---|---|
| 尺 | 15.000秒以下、30fps固定、450フレーム |
| 映像 | H.264 High、yuv420p、BT.709、MP4（faststart） |
| 音声 | AAC-LC 48kHz ステレオ 384kbps、719,872サンプル（AAC 703フレーム＝14.9973秒）。14.5秒以降は無音 |
| ラウドネス | 統合 −14 LUFS（±1）、トゥルーピーク −1 dBTP 以下（実務上の目安。各SNSの公式値ではありません） |
| 文字の安全域 | 9:16：x120–780（y≤840 は x≤888）× y288–1248／16:9：x96–1758 × y183–693（加えて上端の x496–1445 × y38–183） |
| 読む速さ | 台詞テロップは1回の表示ごとに 4.8字/秒以下（句読点を除き、半角は0.5字） |

## 自動QA（`tools/qa.py`）

書き出した MP4 と、書き出し時に記録した各要素の外接矩形（`out/*.qa_boxes.json`）から機械的に判定します。1項目でも外れると終了コード1を返します。

1. 尺・形式：映像450フレーム、コンテナ15.000秒以下、音声719,872サンプル、コーデック・色域・faststart
2. 音：−14±1 LUFS、トゥルーピーク −1.0 dBTP 以下
3. 安全域：テロップ・ラベル・ロゴが安全域内。顔は0.4秒を超えてはみ出さない
4. 重なり：文字要素同士、文字要素と頭部（髪を含む）、頭部同士がいずれも0
5. 読了：台詞は1回ごと、名札・ラベルは同じ文字列の累計で 4.8字/秒以下（小畑ほか, 1985）
6. 冒頭：0フレーム目に顔、4.5秒までにロゴまたは「ユニコ」表記
7. 相方の見え方：中塚の顔が見えるフレーム40%以上、台詞の字数の中塚比率40%以上、2人が並ぶときの頭の大きさは中塚≥リッチャン☆、最後の台詞は中塚
8. 点滅：輝度差10%以上の往復が画面の25%以上で起きる回数が、どの1秒間でも3回以下（ITU-R BT.1702 の考え方にもとづく簡易判定）

## 作り直し・差し替えの手順

### フォルダ構成

| パス | 役割 |
|---|---|
| `cm.html` / `engine.js` / `scenes.js` | 描画（Canvas 2D・外部ライブラリなし）。文言は `scenes.js` の `COPY`、秒は `T`、座標は `LAY` |
| `cues.json` | 効果音の位置、音楽を止める区間、本人の声の配置 |
| `tools/audio.py` | 自作ジングルと自作効果音の合成（第三者の音源は不使用。乱数シード固定で毎回同じ音） |
| `tools/master.py` | ラウドネス調整（−14 LUFS／トゥルーピーク制限／サンプル数の固定） |
| `tools/render.mjs` | ヘッドレスChromiumで1フレームずつ描画し、ffmpeg で MP4 にする |
| `tools/qa.py` | 自動QA（上記） |
| `tools/sheet.py` | 確認用のコンタクトシート |
| `tools/build_page.py` | 共有用の企画書ページの生成（入力の企画データは非公開の場所に置く） |
| `tools/prepare_assets.py` | 手元の原本写真・ロゴから切り抜き素材を作る（ローカル処理・外部API不使用・EXIF/GPSは引き継がない） |
| `tools/fetch_fonts.sh` | 書体（SIL OFL 1.1）を Google Fonts から取得 |
| `build.sh` | 一括実行 |

### 初回の準備

```bash
cd cm/unico-15s
pip install "rembg[cpu]" opencv-python-headless pillow numpy scipy imageio-ffmpeg
npm i -g playwright   # Chromium が入っていない環境のみ
mkdir -p private
# 原本を置く: private/unico_photo.jpg（2ショット写真）, private/logo.jpg（ロゴ・目あり）, private/logo_noeyes.jpg（ロゴ・目なし）
python3 tools/prepare_assets.py
./tools/fetch_fonts.sh
```

### 書き出し

```bash
./build.sh        # 9:16 と 16:9 を out/ に書き出し、out/qa_report.json に自動QAの結果
./build.sh 916    # 縦だけ
```

プレビューは `npx serve .` などで `cm.html?fmt=916`（縦）／`cm.html?fmt=169`（横）を開きます。「UIセーフゾーン」をオンにすると、各SNSのボタンなどが重なる範囲が赤く表示されます。入稿にはマスター（`out/unico_cm15_*.mp4`）を、チャットやページでの共有には軽量版（`*_web.mp4`）を使ってください。

### 媒体別・条件別の差し替え（`scenes.js` の `COPY`）

| 用途 | 変更点 |
|---|---|
| TikTok・Instagram・X の通常投稿 | `cta: 'フォローしてね'`、`endR: 'フォロー！'` |
| 「吉本」の表記を使わない版 | `name: ['芸人コンビ、', 'ユニコ！']` |

文言を変えたら `./build.sh` を実行し、QA（特に読了と重なり）が合格することを確認してください。

### 本人の声を入れる

1. アフレコ台本の秒（`cues.json` の `voice_windows`）に合わせて収録し、WAV を `voice/` に置きます（例：`voice/n_01.wav`）。本人の実声のみを使い、合成音声で本人の声を作ることはしません。
2. `cues.json` の `voice` に `{"file": "voice/n_01.wav", "t": 0.05}` の形で開始秒を登録します。
3. `./build.sh` を実行します。声のある区間は音楽が自動で約6dB下がり、全体のラウドネスは再調整されます。
