# ユニコ 15秒CM『推しが、お笑いの相方に。』篇（常用版 E0）

お笑いコンビ「ユニコ」（中塚サンフラワー／リッチャン☆）の15秒CMを、毎回同じ絵と音で作り直せるようにした制作一式です。

- **出力**：3本あり、いずれも 15.000秒・450フレームです。
  - E0-YT（9:16・Shorts）
  - E0-SNS（9:16・TikTok／Instagram／X の通常投稿。エンドカードは「フォローしてね」）
  - E0-169（16:9・X／会場／広告素材）
- **1コマンドで全工程**：`./build.sh` を実行すると、次の順に処理します。
  1. 自作の音楽と効果音を合成し、ラウドネスを調整する
  2. 書き出す
  3. 自動QAをかける
  4. 納品物を作る
- **公開しないもの**：次のものはこのリポジトリに入れていません（`.gitignore` で場所単位に除外しています）。
  - 肖像写真・ロゴ・声・書体ファイル・書き出した動画
  - 企画データ
- **権利**：コードは MIT です。ただし、名称・ロゴ・肖像・台詞・サウンドロゴは対象外です（[NOTICE](NOTICE)）。

## 仕上がり仕様

| 項目 | 値 |
|---|---|
| 尺 | 15.000秒以下、30fps固定、450フレーム。コンテナの尺も各トラックの実尺（mdhd／elst）も 15.000秒以下 |
| 映像 | H.264 High、yuv420p、BT.709、MP4（faststart）。マスターは上限 14Mbps |
| 音声 | AAC-LC 48kHz ステレオ、公称 384kbps。718,848サンプル（AAC 702フレーム＋エンコーダ遅延＝14.9973秒）。14.5秒以降は無音 |
| ラウドネス | 統合 −14 LUFS（±1）、トゥルーピーク −1 dBTP 以下。実務上の目安で、各SNSの公式値ではありません |
| 文字の安全域 | 9:16：x120–780（y≤840 は x≤888まで）× y288–1248<br>16:9：x96–1758 × y183–693、上端の x496–1443 × y38–183 |
| 読む速さ | 台詞：1回の表示ごとに 5.6字/秒以下（4.8字/秒を超えるものは参考として報告）<br>名札・ラベル：1回1.0秒以上かつ 8字/秒以下<br>字数の数え方：句読点を除く。半角は0.5字 |
| 文字の大きさ | 全文字 40px 以上、台詞 56px 以上（短辺1080換算） |

## 自動QA（`tools/qa.py`）

書き出した MP4 と、書き出し時に記録したデータ（`out/*.qa_boxes.json`）から機械的に判定します。記録しているのは、各要素の外接矩形、読める状態かどうか、2人のステッカーの間隔です。不合格が1件でもあれば、終了コード1を返します。参考値（warnings）は報告だけで、不合格にはしません。

1. **尺・形式**
   - 映像：450フレーム・30fps・所定の解像度
   - 尺：コンテナ・各トラックの実尺・編集リストがすべて 15.000秒以下
   - 音声：718,848サンプル・ステレオ
   - 形式：コーデック・色域・faststart
2. **音**：−14±1 LUFS、トゥルーピーク −1.0 dBTP 以下
3. **安全域**：テロップ・ラベル・吹き出しのしっぽ・ロゴが安全域内にあること。顔のはみ出しは0.4秒まで
4. **重なり**：次の重なりがすべて0であること
   - 文字要素同士
   - 文字要素（しっぽを含む）と頭部（髪を含む）
   - 頭部同士
5. **間隔**：同じ画面の2人のステッカー（白フチ込みの外形）が20px以上離れていること
6. **読む速さ**：上記の基準（枠が9割以上の大きさで、不透明になってからの秒で数える）
7. **文字の大きさ**：上記の下限
8. **冒頭**：0フレーム目に顔があり、4.5秒までにロゴか「ユニコ」の表記が出ること
9. **相方の見え方**
   - 中塚の顔が見えるフレームが40%以上
   - 台詞の字数に占める中塚の比率が40%以上
   - 2人が並ぶとき、頭の大きさは中塚≥リッチャン☆
   - 最大の打撃音の瞬間は中塚だけが映る
   - 最後の台詞は中塚
10. **点滅**：輝度差10%以上の往復が画面の25%以上で起きる回数が、どの1秒間でも3回以下（ITU-R BT.1702 の考え方にもとづく簡易判定）

## 作り直し・差し替えの手順

### フォルダ構成

| パス | 役割 |
|---|---|
| `cm.html` / `engine.js` / `scenes.js` | 描画（Canvas 2D・外部ライブラリなし）。文言は `scenes.js` の `COPY`、秒は `T`、座標は `LAY` |
| `cues.json` | 効果音の位置（比率ごとの差分を含む）、音楽を止める区間、本人の声の配置 |
| `tools/audio.py` | 自作ジングルと自作効果音の合成（第三者の音源は使っていません。乱数シードを固定しているので毎回同じ音になります） |
| `tools/master.py` | ラウドネス調整（−14 LUFS、トゥルーピークの制限、サンプル数の固定） |
| `tools/render.mjs` | ヘッドレスChromiumで1フレームずつ描画し、ffmpeg で MP4 にする |
| `tools/qa.py` | 自動QA（上記） |
| `tools/sheet.py` | 確認用のコンタクトシート |
| `tools/build_page.py` | 社内限定の企画書ページの生成（入力の企画データは `private/` に置き、公開しない） |
| `tools/prepare_assets.py` | 手元の原本写真・ロゴから切り抜き素材を作る（ローカルで処理し、外部APIは使いません。EXIF／GPSは引き継ぎません） |
| `tools/fetch_fonts.sh` | 書体（SIL OFL 1.1）を Google Fonts から取得 |
| `build.sh` | 一括実行 |

### 初回の準備

```bash
cd cm/unico-15s
pip install "rembg[cpu]" opencv-python-headless pillow numpy scipy imageio-ffmpeg
npm i -g playwright   # Chromium が入っていない環境のみ
mkdir -p private
# 原本を置く: private/unico_photo.jpg（2ショット写真）, private/logo.jpg（ロゴ）
python3 tools/prepare_assets.py
./tools/fetch_fonts.sh
```

### 書き出し

```bash
./build.sh        # 全版を out/ に書き出し、自動QAの結果を out/qa_report.json に出す
./build.sh 916    # 縦（E0-YT と E0-SNS）だけ
```

`out/` にできるもの：

| ファイル | 用途 |
|---|---|
| `unico_cm15_916.mp4` / `unico_cm15_916_sns.mp4` / `unico_cm15_169.mp4` | 入稿用マスター（E0-YT／E0-SNS／E0-169） |
| `*_web.mp4` | 共有・プレビュー・X 投稿用の軽量版（映像は最大6Mbps） |
| `unico_cm15_916_se.mp4` / `unico_cm15_169_se.mp4` | BGMを抜いた効果音だけの版 |
| `stills/*_f404.png` / `stills/*_f449.png` | エンドカードの静止画（Aの最終フレーム／Bの決め画面） |

プレビューは、`npx serve .` などで次のURLを開きます。
- 縦：`cm.html?fmt=916`
- 横：`cm.html?fmt=169`
- SNS版：`cm.html?fmt=916&variant=SNS`

「UIセーフゾーン」をオンにすると、各SNSのボタンなどが重なる範囲が赤く表示されます。文言や座標を変えたら `./build.sh` を実行し、QAが合格することを確認してください。

### 本人の声を入れる

1. `cues.json` の `voice_windows` の秒に合わせて収録します。WAV は `voice/` に置きます（例：`voice/n_01.wav`）。
   - 使うのは本人の実声だけです。合成音声で本人の声を作ることはしません。
   - `voice/` はコミットしないでください（`.gitignore` 済み）。
2. `cues.json` の `voice` に、`{"file": "voice/n_01.wav", "t": 0.05}` の形で開始秒を登録します。
3. `./build.sh` を実行します。声のある区間では、次の処理が自動でかかります。
   - 音楽と効果音を約6dB下げる
   - 2.0〜3.0秒のサウンドロゴ①はリードを約10dB下げる
   - 全体のラウドネスを再調整する
