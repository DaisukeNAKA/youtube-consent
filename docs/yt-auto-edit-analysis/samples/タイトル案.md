# タイトル案（5案）

動画: ユニコ 10分ラジオ #8「本当にあったメルカリの怖い話」（冒頭5分の編集版）
※ 各案は全角28字以内。数字は半角。

| # | 型 | タイトル案 | ねらい |
|---|----|-----------|--------|
| 1 | 数字 | 【評価500件】メルカリで本当にあった怖い話2つ | 具体的な数字で信頼と規模を出す |
| 2 | 断定 | メルカリは出品者のプロフで態度が変わります | 体験から導いた断定で立ち止まらせる |
| 3 | ネガ/ポジ対比 | 売れない→妻のアカウントで出したら売れすぎた | 落差で興味を引く |
| 4 | 疑問 | 一人暮らし女性はコンビニでアイスを買っちゃダメ？ | 動画内の「え？なんで」を検索意図に |
| 5 | 体験型 | 芸人ユニコがメルカリ500件やって出会った怖い客 | 一次体験の信頼感、固有名詞で指名検索 |

## 推し案
- 第1候補: 案2（理由: 本編の見出し「出品者の態度が全然違う」がそのまま主張になる）
- 第2候補: 案3（理由: 前半の山場「妻のアカウントで出品したら」を落差で表現）
