スキルファイルって何？
はじめての人向けに、一言で説明します。
「スキル」というのは、AIに覚えさせる"手順のセット"のことです。
普段のAIは、毎回イチから「こうやって、次にこうして……」とお願いしないと動いてくれません。でもスキルを入れておくと、その手順一式をAIが最初から知っている状態になります。
このスキルの場合は、「喋った動画を受け取ったら → 文字に起こして → テロップにして → 間を詰めて → 縦型で書き出す」という一連の手順を、AIに丸ごと覚えさせてあります。
だからあなたは、細かいやり方を知らなくていい。動画を渡して「これ、縦のテロップ動画にして」と言うだけで、AIが覚えた手順どおりに全部やってくれる、というわけです。
「AIに、ポンコツのぼくでも回せる"テロップ係"を1人インストールする」。そんなイメージで大丈夫です。
