## 残った差分（スキルでは吸収しない／できない）
1. 素材固有: ユニコ素材には TikTok ライブのオーバーレイ（番組名・名前タグ）が焼き込まれており、正解動画のような無地の画面にはならない。スキルの責任範囲外。
2. 二人トークの話者表示（名前・色分け）は正解動画（一人語り）に存在せず、スキルも持たない。
3. 4K 出力・ダイジェスト・BGM は正解動画（本人11分動画）にはあるがスキル標準外（Brain記載どおり）。設定 resolution=4K で比率保持の4K描画は可能。
4. 処理速度: 本コンテナ（4コアCPU・GPUなし）では 40秒試作 ≈3分、5分本編 ≈40〜60分。Brain の実測（M2 Air: 40秒4分、4分本編9分）とは環境差。

## 結論
v3 で正解動画との幾何・スタイル差分は計測上すべて許容範囲（±0.01H 以内）に収まり、字幕分割・SRT・同期の実ずれも解消した。v3 を確定版とする。
