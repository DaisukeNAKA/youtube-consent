# スナックゆに子 音質改善メモ（#29 の実測にもとづく）

対象素材: `DJI_20260915135827_0021_D.MP4`（Osmo Pocket 3 ＋ DJI Mic Mini 2 送信機2台を OsmoAudio 直結、48 kHz / 16-bit / AAC、L=話者A / R=話者B）
解析日: 2026-09-21

## 1. 実測でわかったこと

| 項目 | 実測値 | 判定 |
|---|---|---|
| 真のピーク（32bit float デコード） | ch0 +0.53 dBFS / ch1 +0.20 dBFS | クリップではない |
| 0 dBFS を超えたサンプル数 | 1億1,481万中 16〜18 個（0.1〜0.2 ppm） | 事実上ゼロ |
| 圧縮の折れ点（回り込みを未圧縮基準にした入出力カーブ） | ch1 は約 −18 dBFS から傾き 0.60〜0.76（≒1.4〜1.7:1）、ch0 は 0.92 でほぼ素通り | リミッター作動 |
| 最大 1 秒窓のピーク | −2.1〜−3.6 dBFS に密集 | 天井あり |
| レベル別の非調和成分比 | 音量が上がるほど改善（−0.2 → −13.3 dB） | 歪みは増えていない |
| 2本のマイクの分離 | ch0 話者 4.0 dB / ch1 話者 6.5 dB（中央値） | 致命的に低い |
| チャンネル間の遅れ | 1.96 / 2.15 ms（相関 0.55〜0.61） | 約 70 cm の行路差 |
| 長時間平均話声スペクトル比 | 250〜630 Hz が +9〜+12 dB 過剰、4〜10 kHz が −6〜−12 dB 不足 | 胸元ラベリアの指紋 |
| ノイズフロア | −52.3 dBFS RMS（発話中央値 −19〜−20 dBFS） | S/N 約 33 dB |

**結論**: 「大きな声でクリップする」の正体は digital clipping ではなく、DJI が公式に **Clipping Control**（自動リミッター）と呼ぶ機能の作動。
ただし MV7 との音質差の主因はリミッターではなく、**分離の低さ・残響・スペクトルの偏り**。

## 2. 収録側の対策（効果が大きい順・ほぼ0円）

1. **マイクの装着位置** — 胸の中央ではなく襟の端、マイク軸を口へ向け、口から 15〜20 cm（DJI 公式推奨）。直接音が上がり、分離・残響比・高域がまとめて改善する。
2. **2人の距離を広げる** — 現状 約70 cm。1.4〜1.5 m まで離すと回り込みが約 6 dB 減る。
3. **正対をやめて「ハの字」に座る** — 互いの口が相手のマイク正面を向かないようにする。無指向性でも頭部の遮蔽で 2〜4 dB 稼げる。
4. **ノイズキャンセルを弱／OFF** — Mic Mini 2 の 2 段階 NC は強くかけると子音（4 kHz 以上）も削る。屋内なら不要。
5. **送信機ゲインを下げる** — 現状はリミッター前で +4.5〜+6 dBFS 相当に達している推定。ピークが −12〜−18 dBFS に収まるまで下げる。
6. **Clipping Control の扱い** — Pocket 3 の 設定 > ワイヤレスマイク に項目がある想定（DJI 公式 OsmoAudio 互換表で Pocket 3 は Clipping Control 対応）。**ただし互換表は「対応機能の一覧」であって UI の設定項目一覧ではないため、実機で項目の有無を確認すること。** オフにする場合は必ず先にゲインを下げること（Mic Mini 2 には保険の内蔵録音が無い）。
7. **部屋** — 2人の背後の壁に厚手の毛布かカーテン（壁から 5〜10 cm 離して吊る）、机の天板にラグやフェルト。250〜630 Hz の膨らみに効く。1〜2 cm の薄い吸音フォームはこの帯域にほぼ効かない。

### 設定画面の場所（Osmo Pocket 3）
- 送信機のパラメータ: 画面上端から下スワイプ → コントロールメニュー → 歯車 → 下にスクロール → **ワイヤレスマイク**
- ゲインなどのクイック操作: 撮影画面で右端から左スワイプ → **Audio**（外部マイク接続時に効くのは Channel と Gain のみ。風切り音低減と指向性オーディオは無効になる）
- 2人を L/R に分ける: 設定 > ワイヤレスマイク の **Audio Channel = Stereo** と **Channel Assignment（TX1→L / TX2→R）**

## 3. ポスプロで「できること・できないこと」

### できる（実証済み）
長時間平均話声スペクトルからの乖離（RMS）が **12.98 dB → 5.71 dB** に改善。
4〜10 kHz の不足が **−24.0 dB → −8.8 dB**、250〜630 Hz の過剰が **+4.6 dB → +0.9 dB**。

### できない
- **回り込みと残響の除去** — 分離 4〜6.5 dB は物理的に後から分離できない。AI ディリバーブは逆畳み込みではなく再合成なので、直接音対残響比が 8〜10 dB しかない素材では副作用が勝つ。
- **近接効果の低域** — 80〜160 Hz は信号がノイズフロアと同レベル。持ち上げても部屋の低域ノイズが上がるだけ。
- **リミッターの完全な復元** — Mic Mini 2 は送信機内蔵録音が無いため、処理前の信号が存在しない。

## 4. Premiere Pro での手順

1. **L/R を2本のモノラルに分ける** — プロジェクトパネルでクリップを右クリック → **変更 > オーディオチャンネル**、またはクリップを右クリック → **Breakout to Mono**。
   ※ エッセンシャルサウンドの「スピーチを強調」はステレオクリップに掛けるとモノラルのダウンミックスしか出力しない。L/R に別人が入っている本素材では必ず先に分離すること。
2. **各トラックにパラメトリックイコライザー**（実測から導いた値）
   - ハイパス 85 Hz
   - 300 Hz / Q 1.1 / **−4.5 dB**
   - 500 Hz / Q 1.0 / **−7.0 dB**   ← 最も効く
   - 750 Hz / Q 1.2 / **−3.5 dB**
   - 2.6 kHz / Q 1.4 / **+2.0 dB**
   - 4.5 kHz / Q 1.2 / **+5.5 dB**
   - 7 kHz ハイシェルフ / **+5.0 dB**
3. **ノイズ低減** — エッセンシャルサウンド > 修復 > ノイズを軽減。**20〜30% にとどめる**（強くかけると 4 kHz 以上が削れ、EQ の効果を打ち消す）。
4. **喋っていない側を下げる** — トラックごとにノイズゲートか、手作業で不要部分をカット。分離が低いので完全には取れないが、−10〜−15 dB 下げるだけで見通しが良くなる。
5. **コンプレッサー** — しきい値 −18 dB、レシオ 2:1、アタック 10 ms、リリース 150 ms。素材側で既に 1.5:1 かかっているので、これ以上深くしない。
6. **ラウドネス** — 書き出しで −14 LUFS、True Peak −1.5 dBTP。**−13 LUFS まで上げると素材側のリミッターと二重に効いて「詰まった」印象が強まる。**
7. **モノラルにまとめる場合の注意** — 2 ms の遅れがあるため単純加算すると 250 Hz 付近に櫛形の谷ができる。2トラックのまま左右に少し振るか、喋っていない側を下げてから合算する。

## 5. Filmora での制約
- DeClip・ディエッサー・コンプレッサー・リミッターは**内蔵されていない**（内蔵「オーディオエフェクト」は視覚効果）。ディリバーブのみ内蔵。
- ステレオクリップの L/R を分離する機能が公式ドキュメントに無い。本用途では致命的。
- 14.7.12 以降は **VST3 プラグイン**に対応（Mac は `/Library/Audio/Plug-Ins/VST3/`）。使うならここからコンプ・EQ を持ち込む。
- 本素材については **Premiere 側で処理するのが妥当**。
