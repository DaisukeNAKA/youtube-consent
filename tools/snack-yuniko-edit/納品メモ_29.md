# 整音 v2（2026-09-22）

## なぜやり直したか

初版の整音チェーンに3つの不具合があり、**#18（e935 + P4next の SD 録音）のスペクトルからの乖離が、無処理のカメラ音声より悪化していました**。

1. **`afftdn` に `tn=1` を付けると `nr` が完全に無視される。** `nr=0.01` と `nr=97` の出力がバイト単位で一致することを確認。プラン値の `nr=14` は一度も効いていませんでした。
2. **`nf=-40` は削り過ぎ**で、音声自身の高域まで持っていきます（8 kHz 帯が無処理の 16.7 に対し 9.8 まで低下）。ミュージカルノイズの指標も 22.1 と突出（無処理 8.35）。
3. **音声を 16bit で取り出していた**ため、AAC デコード後に 1.0 を超えるサンプルが潰れていました。

加えて、補正 EQ の目標を Byrne (1994) の長時間平均話声スペクトルに置いていたこと自体が誤りでした。実測すると **#18 は 1〜4 kHz で LTASS より 6〜10 dB 明るく**、近接カーディオイドと P4next の TONE がそう作っています。
